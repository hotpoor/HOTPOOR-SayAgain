# 技术标识来源

这些图片仅用于说明 SayAgain 使用的技术及上游项目，不表示合作或背书。保留原始图片；通过 README 的尺寸属性显示，不重绘品牌标识。

- 通用技术图标来自 Devicon v2.17.0（MIT），附 `devicon-LICENSE.txt`。
- ONNX、FFmpeg 图标来自 Simple Icons 15.16.0（CC0），附 `simple-icons-LICENSE.txt`。
- SVG 标识来自 W3C；项目 / 厂商标识来自各自官方站点或仓库，标识权利属于相应权利人。
- Qwen3-TTS、3D-Speaker 的图示明确代表其上游项目；不作为全部同厂模型的独立 Logo。
- SenseVoice README 中找到的是模型架构图，未把它当 Logo 使用；sherpa-onnx、FunASR、CosyVoice、FSMN、Zipformer 等在本次核对材料中未取得可确认的独立 Logo，保留原项目文字链接。
